# SPMIDDLE — CONTRATOS

<a id="api-surface"></a>
## API surface

- Contratos públicos expostos aos consumidores: criação de client/rest, schema, repositories, provisioning e helpers.

<a id="query-contract"></a>
## Query contract

- Forma do query, allowlists, paginação e serialização/escaping.

<a id="schema-contract"></a>
## Schema contract

- Modelagem de listas/fields, constraints e evolução aditiva.

<a id="error-catalog"></a>
## Error catalog

- Erros tipados, códigos estáveis e regras de tradução (fail-closed).

<a id="limits"></a>
## Limits

- Limites de payload, paginação e proteções anti-abuso; comportamentos de falha segura.

<a id="provisioning"></a>
## Provisioning

- Fluxo `inspect → plan → apply → verify`, idempotência e limites (sem rollback destrutivo).
